# Variation — VD (Experimental)

`mGRG`STensor`` 패키지의 `Variation.m`에서 제공하는 변분 도함수(variational derivative) 함수이다.

---

### VD

#### 함수 시그니처

```wolfram
VD[arg, expr]
VD[arg, expr, opts]
```

#### 설명 (Details)

`VD[arg, expr]`은 표현식 `expr`을 `arg`에 대해 변분한 결과를 나타낸다.

- **선형성(Linear)**: 상수 계수와 합에 대해 선형으로 분배된다.
- **라이프니츠 규칙(Leibniz rule)**: 곱에 대해 곱의 미분법을 적용한다.
- **스칼라 함수**: Log, 거듭제곱 등 스칼라 함수에 대해 체인룰을 적용한다.
- **Tscalar 인식**: `Tscalar` (텐서 스칼라, 예: `v[la] × v[ua]`)를 인식하여 변분한다.

#### 옵션

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `IndependentVD` | `{}` | 변분에 독립인 텐서의 리스트. 지정된 텐서의 변분은 0이 된다. |
| `ByPartsVD` | `False` | `True`로 설정하면 지정된 BD 연산자에 대해 부분적분을 수행한다. |

#### 예제 (Examples)

##### 기본 사용법

```wolfram
Tdefine[f[]]; Tdefine[v[ua], 1]; Tdefine[T, 2]; Tdefine[F, "-ba"]

VD[f[], T[la, lb] × v[ua]]
(* [v^a(δ_fT_ab)] + [T_ab(δ_fv^a)] *)
```

##### 선형성과 라이프니츠 규칙

```wolfram
SetAttributes[{c1, c2}, Constant]

VD[f[], c1 T[la, lb] × v[ua] + c2 v[la]]
(* c1 [v^a(δ_fT_ab)] + c2 [(δ_fv_a)] + c1 [T_ab(δ_fv^a)] *)
```

##### 스칼라 함수에 대한 변분

```wolfram
VD[Metricg[la, lb], Log[f[]]]
(* [1/f (δ_{g_ab} f)] *)

VD[Metricg[la, lb], Log[v[la] × v[ua]]]
(* [v^c/(v_a v^a) (δ_{g_ab} v_c)] + [v_c/(v_a v^a) (δ_{g_ab} v^c)] *)

VD[Metricg[la, lb], (v[la] × v[ua])^n]
(* Log[...] (v_a v^a)^n (δ_{g_ab} n) + n (v_a v^a)^{-1+n} v^c (δ_{g_ab} v_c)
   + n v_c (v_a v^a)^{-1+n} (δ_{g_ab} v^c) *)

VD[Metricg[la, lb], Tscalar[v[la] × v[ua]]]
(* [v^c(δ_{g_ab} v_c)] + [v_c(δ_{g_ab} v^c)] *)
```

##### 텐서에 의한 변분 (Variations by a Tensor)

대칭 계량 텐서:

```wolfram
(* 아래 인덱스 계량의 아래 인덱스 계량에 대한 변분 *)
VD[Metricg[la, lb], Metricg[lc, ld]]
(* 1/2 δ^a_d δ^b_c + 1/2 δ^a_c δ^b_d *)

(* 아래 인덱스 계량의 위 인덱스 계량에 대한 변분 *)
VD[Metricg[la, lb], Metricg[uc, ud]]
(* -1/2 g^ad g^bc - 1/2 g^ac g^bd *)
```

반대칭 텐서:

```wolfram
VD[F[la, lb], F[lc, ld]]
(* -1/2 δ^a_d δ^b_c + 1/2 δ^a_c δ^b_d *)

VD[F[la, lb], F[uc, ud]]
(* -1/2 g^ad g^bc + 1/2 g^ac g^bd *)
```

고차 대칭 텐서 (Riemann 대칭):

```wolfram
Tdefine[R, "abcd+bcad+cabd"]

(* 모두 아래 인덱스 *)
VD[R[la, lb, lc, ld], R[le, lf, lg, lh]]
(* 1/3 δ^a_f δ^b_g δ^c_e δ^d_h + 1/3 δ^a_g δ^b_e δ^c_f δ^d_h
   + 1/3 δ^a_e δ^b_f δ^c_g δ^d_h *)

(* 위 인덱스 포함 *)
VD[R[la, lb, lc, ld], R[le, uf, lg, uh]]
(* 1/3 δ^b_g δ^c_e δ^d_h g^af + 1/3 δ^a_e δ^c_g δ^d_h g^bf
   + 1/3 δ^a_g δ^b_e δ^d_h g^cf *)
```

다른 Kind의 인덱스가 섞인 경우:

```wolfram
VD[R[la, lb, lc, ld], R[le, uμ, lg, lh]]
(* Msg: Different kinds of indices: ub and uμ *)
(* δ^aμ 등의 잘못된 표현 *)

VD[R[la, lb, lc, ld], R[le, lf, lg]]
(* Msg: Different lengths of indices: 4 and 3 *)
(* R_efg — 변환 없음 *)
```

MetricFlag에 따른 동작:

```wolfram
Off[MetricgFlag]
VD[R[la, lb, lc, ld], R[le, uf, lg, lh]]
(* Msg: No metric for Latin *)
(* 잘못된 출력 — metric 없이 인덱스를 올릴 수 없으므로 *)

On[MetricgFlag]  (* 기본 설정 *)
```

다른 Kind의 텐서에 대한 변분:

```wolfram
Tdefine[t[la, lμ]]

VD[t[la, lb], t[uc, ud]]  (* No Greek's metric *)
(* Msg: No metric for Greek *)
(* g^ac δ^bd  -- 잘못된 표현 *)

VD[t[la, lb], t[uc, uμ]]
(* Msg: Different kinds of indices: ub and u μ *)
(* g^ac δ^bμ  -- 잘못된 표현 *)

VD[t[la, lν], t[uc, uμ]]  (* No Greek's metric *)
(* Msg: No metric for Greek *)
(* g^ac δ^νμ  -- 잘못된 표현 *)
```

##### IndependentVD 옵션

사용법:

```wolfram
VD[arg, expr, IndependentVD → {tensor1, tensor2, ...}]
```

변분에 독립인 텐서를 지정한다. 독립 텐서의 변분 도함수는 0이 된다 ($\delta_f T = 0$).

예제:

```wolfram
VD[f[], T[la, lb] × v[ua]]
(* [v^a(δ_fT_ab)] + [T_ab(δ_fv^a)] *)

VD[f[], T[la, lb] × v[ua], IndependentVD → {T}]  (* δ_fT = 0 *)
(* [T_ab(δ_fv^a)] *)
```

##### ByPartsVD

사용법:

```wolfram
VD[arg, expr, ByPartsVD → True]
VD[arg, expr1, expr2, ByPartsVD → True]
```

`ByPartsVD`를 `True`로 설정하면 BD 연산자에 대해 부분적분을 수행한다. 경계항은 버려진다.

```wolfram
BD[lb, v[lc]] × BD[ub, v[uc]]
(* ∂_av_b ∂^av^b *)

VD[v[la], %, ByPartsVD → True]
(* -∂_b∂^bv^a - ∂^b∂_bv_c g^ac *)
```
$$\int \delta_{v_a}\left[(\partial_b v_c)(\partial^b v^c)\right] = \int (\partial_b v_c)\,\delta_{v_a}(\partial^b v^c) + \int (\partial^b v^c)\,\delta_{v_a}(\partial_b v_c)$$

$$= -\int (\partial^b \partial_b v_c)\,g^{ac} - \int (\partial_b \partial^b v^c)\,\delta_c^a$$

옵션 ByPartsVD를 사용할 때의 두 번째 인자 `expr1`과 세 번째 인자 `expr2` 사용법:

```wolfram
VD[v[la], BD[lb, v[lc]], BD[ub, v[uc]], ByPartsVD → True]
(* -∂_b∂^bv^a *)
```
$$\int (\partial^b v^c)\,\delta_{v_a}(\partial_b v_c) = -\int (\partial_b \partial^b v^c)\,\delta_c^a$$

```wolfram
VD[v[la], BD[ub, v[uc]], BD[lb, v[lc]], ByPartsVD → True]
(* -∂^b∂_bv_c g^ac *)
```
$$\int (\partial_b v_c)\,\delta_{v_a}(\partial^b v^c) = -\int (\partial^b \partial_b v_c)\,g^{ac}$$
